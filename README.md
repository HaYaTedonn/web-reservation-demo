# ネット予約システム（デモ）

飲食店・サロン・クリニックなどの店舗向け **ネット予約システム** のデモです。
お客様の予約から、店舗側の予約管理ダッシュボードまでを一通り体験できます。

🔗 **ライブデモ:** https://hayatedonn.github.io/web-reservation-demo/
（店舗側の管理画面 → https://hayatedonn.github.io/web-reservation-demo/admin.html ）

## 主な機能
**お客様側（`index.html`）**
- メニュー選択 → 日付選択（◯△× の空き状況表示）→ 時間枠選択 → 情報入力 → 予約完了の4ステップ
- 予約番号の発行、料金・所要時間の自動表示
- スマホ最適化（モバイルファースト）

**店舗側（`admin.html`）**
- 日付ごとの予約一覧（時間順）・予約の取消
- KPI（本日／今週の予約数・売上見込・累計）
- メニュー別の人気ランキング
- お客様の予約がリアルタイムに反映

## 技術ポイント
- 営業時間・定休日・所要時間・席数を考慮した **時間枠の重複判定ロジック**
- 設定（店名・メニュー・営業時間）を1か所にまとめ、**別の店舗へ再スキン可能**
- 依存ライブラリなしのバニラ JavaScript ＋ PWA 志向の軽量実装

## 構成
- `index.html` … お客様の予約画面
- `admin.html` … 店舗の予約管理ダッシュボード
- `assets/data.js` … 予約データ・時間枠ロジック・集計（共有データ層）

## 補足
表示データは架空の店舗（SALON LUMINA）・サンプルです。実装版では、確認メール／LINE通知、事前決済、Googleカレンダー連携、複数スタッフ対応などを追加できます。
